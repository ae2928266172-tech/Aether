# 收银系统

多门店、多设备共用数据的收银与库存管理系统：后台管理、门店工作台（收银 + 订单）、顾客扫码点单。
2026-11 从零重写。

| 部分 | 技术 | 目录 |
| --- | --- | --- |
| 后端 API | Python 3.13 / FastAPI / SQLAlchemy（试用 SQLite，上线 PostgreSQL） | `backend/` |
| 后台管理 | 网页，Vue 3 + Element Plus（已放在 `web/vendor`，不需要编译） | `web/admin/` |
| 门店工作台 | 网页；门店收银电脑装“收银系统”桌面软件打开（也能用浏览器） | `web/store/` |
| 桌面收银软件 | Windows 安装包（Electron 22，Win7 到 Win11、32/64 位通用），打开门店工作台、直接出票 | `desktop/` |
| 顾客点单 | 网页版（小程序上线前先用）；小程序和安卓 / 鸿蒙 / iOS 客户端为后续阶段 | `web/h5/` |
| 计划与说明 | 分阶段计划、上线差距与成本 | `docs/` |

## 本机试用

```powershell
.\start.ps1
```

浏览器打开 `http://127.0.0.1:8000`。初始管理员 `admin` / `admin123`（**上线前必须修改**，或启动前设置环境变量 `SHOUYIN_ADMIN_PASSWORD`）。
想要演示数据：另开一个终端运行 `python backend\scripts\demo_data.py`（门店账号 store1 / store2，密码 store123）。

## 桌面收银软件（Windows）

门店收银电脑装 `收银系统-安装-x.y.z.exe`，桌面出现“收银系统”图标，双击即打开收银台。第一次打开会弹出“桌面软件设置”：

- **收银系统地址**：放系统那台电脑（或云服务器）的地址，例如 `192.168.31.10:8765`。所有门店连同一个地址，数据共用。
- **小票机**：选 POS58。出票方式默认“直接出票”（服务端生成 ESC/POS 指令，软件经 Windows 打印后台原样发给小票机，不弹框）；乱码或不出纸时改“用打印机驱动出票”；没接小票机选“不出票”。可打印测试页。
- 现金收款弹钱箱、开机自动打开、打开即全屏（`F11` 切换）。设置随时可用 `Ctrl+Shift+S` 或收银台“本机设置”打开。
- 连不上服务器时显示提示页，每 15 秒自动重连。后台管理链接会用系统浏览器打开。

**键盘收银**（网页版也能用）：扫码枪不用点输入框，直接扫；`F1` 搜索，`Enter`（搜索框为空时）或 `F2` 收款，收款框里 `F1`~`F4` 选现金 / 微信 / 支付宝 / 其他、`Enter` 确认；`↑` `↓` 选商品，`+` `−` 改数量，`F6` 输入数量，`Delete` 删除，`Ctrl+Delete` 清空；`F3` 挂单，`F4` 取单（数字键选单），`F7` 备注，`F8` 补打上一单，`F9` 开钱箱，`Alt+1`~`5` 切换收银 / 订单 / 交班 / 库存 / 要货。选规格、多规格条码也可按数字键。

**屏幕键盘**（触摸屏收银机用）：收银页搜索框旁边固定一块字母数字键盘，收款框自带数字键盘；其他输入框（备注、数量、登录）手指点一下就弹出浮动键盘，“确认”等于回车。“本机设置”里可选触摸时弹出（默认）/ 总是弹出 / 关闭；键盘快捷键提示默认隐藏，也在“本机设置”里打开。

打安装包（在 Linux 需要装 wine 和 wine32）：

```bash
cd desktop
npm install
npm test                 # 设置、打印编码、扫码枪识别等单元测试
npm run dist             # 生成 dist/收银系统-安装-1.0.0.exe
```

`desktop/e2e/store-keyboard.js` 用浏览器把键盘收银整套走一遍（需先启动服务端并写入演示数据）。

## 数据库备份与恢复

- 每天自动备份：在收银系统文件夹里运行一次 `.\install_backup_task.ps1`（默认每天 22:30，可加 `-At 23:00`）。电脑那时关机的话，下次开机后补做。
- 备份放在 `%LOCALAPPDATA%\shouyin\backups`，另存一份到本文件夹的 `数据库备份\`（在 OneDrive 里，会同步到云端），各保留最近 30 份；商品图片一起增量备份。日志在 `%LOCALAPPDATA%\shouyin\backup.log`。
- 收银进行中也可以备份（用 SQLite 在线备份接口，拷完先做完整性检查再压缩）。手动备份：`.\backup.ps1`。
- 恢复演练（不动正在用的数据库）：`python scripts\restore_db.py 备份文件夹 --check`，会显示备份里和当前库里的订单、商品等行数。
- 真正恢复：先停掉服务端，再运行 `python scripts\restore_db.py 备份文件 --yes`。原来的数据库会另存为 `shouyin.db.before-restore-时间`。运行脚本前要设好和 start.ps1 一样的 `DATABASE_URL`。

## 主要业务规则

- **商品与库存分开**：商品规格（顾客看到的名称、售价）绑定“库存品”和“扣减量”。例如“小份”扣 1 份、“大份”扣 2 份，另一个名称的商品也可以扣同一个库存品。
- **多门店**：每个门店有自己的库存；仓库单独入库、出库，每天“调拨”到门店，同时减仓库、加门店。台账查期初、入库、出库、调入、调出、销售、退货回补、盘点、结余。
- **区域二维码**：每个区域属于一个门店，顾客扫码下单，订单自动带上门店和区域。旧码可以作废重发。
- **打折 / 调低应收**：只影响本单，不改商品售价，库存照实际件数扣。只能调低。角色和账号可分别设置能否打折、能否调低、最低几折、单笔最多调低多少。
- **订单状态**：待接单 → 已接单 → 已完成（收款后）；未收款可取消（库存退回）；已收款走退货退款，支持部分退，默认退回原门店库存，可选“不回库存”（损坏品）。重复点击和网络重试不会重复收款、扣库存或退款。
- **库存不够也可以卖**（门店收银和小程序都允许，后台“业务规则”可以关）；小程序订单下单即扣库存。
- **权限**：门店员工只能操作绑定的门店（可绑定多家）；营收报表、商品销售核对只开放给后台；门店能否看 / 改本店库存由后台按门店设置。
- **收款是记账**：现金、微信、支付宝、其他都是店员确认收款后记账，**不是在线支付**。接入微信 / 支付宝自动扣款和原路退款需要商户号，是单独的工作。
- **小票**：58 / 80mm，后台设置标题、抬头、底部文字、底部图片（如微信二维码）、打印哪些字段、是否打印医疗器械资料。门店新订单自动提示音 + 自动打印，订单里可以补打，内容都来自该订单本身。
- **两种出票方式**（后台“门店与区域”按门店设置）：
  - 本机浏览器：小票机接在开门店工作台的电脑上，浏览器打印；`tools/门店电脑一键设置.bat` 用 Windows 自带 Edge 设为不弹框直接出票。
  - 打印小助手：小票机接在另一台电脑上（包括只有 IE 的 Win7）。那台电脑装 `tools/print-agent`（后台也能直接下载），它用门店打印密钥向系统取票，把 ESC/POS 指令原样发给 POS58 等小票机，新订单先响铃播报。补打、收银、新订单都会发到这台机器。
