# 收银系统：功能差距清单（2026-11-16）

对照对象：现在用的惠管家（采购进货单、采购退货单、实时盘点单、领用出库、编码 / 条码 / 助记码搜索、导入导出）和常见连锁收银系统。
说明：云端登录不了惠管家后台，所以是按迁移资料和以往在惠管家里操作的记录对照的，没有逐页核对它的菜单。

## 一、本次已补上（分支 `claude/project-thread-88klcw`，第一批测试 44 → 54 个，加上第二批共 62 个，全部通过）

| 功能 | 怎么用 |
| --- | --- |
| 库存预警 | “库存品”里填预警量；任一仓库 / 门店库存 ≤ 预警量时，经营概览出现“库存预警”列表，仓库与库存标红并可只看预警中的，门店库存页显示“该补货了” |
| 拼音助记码 | 商品自动生成拼音首字母（纸杯 → zb），可手改；收银台边输边搜名称、助记码、货号、规格、条码，只剩一个商品时回车直接加入；后台商品搜索也支持 |
| 挂单 / 取单 | 收银台“挂单”把当前购物车存起来先收下一位，“取单”取回（按现价，下架商品会提示）。挂单只存在那台电脑上 |
| 入库进价和金额 | 入库时每行带出库存品成本作为进价，可改，自动算金额和合计（对应惠管家采购进货单）。进价不会自动改库存品成本 |
| 出库原因 | 出库选“领用 / 报损 / 退供应商 / 其他”，退供应商时可选供应商（对应惠管家采购退货单、领用出库单） |
| 盘点盈亏 | 盘点时实时显示每行盈亏；单据保存账面数、实盘数、盈亏数、盈亏金额（按成本） |
| 单据记录 | “仓库与库存 → 单据记录”按类型、地点、日期、单号查所有出入库单，展开看明细、制单人 |
| 单据作废（冲红） | 填错的单据点“作废”并写原因，库存按原单反向冲回，单据保留并标“已作废”；盘点单作废只冲回当时的盈亏 |
| 导出 Excel | 商品资料（每个规格一行，含医疗器械资料）、库存台账、出入库单据 |

## 二、Aether 2026-11-17 的决定与第二批改动

| 问题 | 决定 | 结果 |
| --- | --- | --- |
| 会员 | 不要 | 不做 |
| 批次和有效期 | 要 | 已做：入库每行可填批号、生产日期、有效期至，同一库存品可点“+批次”分几行；出库、调拨、销售先出最早到期的批次，调拨时批次跟着到门店，退货回到原批次，作废按原批次冲回；“仓库与库存 → 批次 / 有效期”查看；经营概览“临期提醒”，提醒天数在“业务规则”里设（默认 30 天）。没录批次的库存照常用，只是不参与临期提醒 |
| 门店要货申请 | 要 | 已做：门店工作台“要货”提交、撤回；后台“仓库与库存 → 要货申请”照单调拨（实发可改，生成调拨单）或驳回，门店看得到结果；新权限“要货申请”已自动给原有的门店角色 |
| 进价更新成本 | 先不自动改 | 保持不改 |
| 门店不同售价 | 先不做 | 不做 |
| 交班 | 要 | 已做：门店工作台“交班”开班填备用金，交班填实点现金，系统按这一班自己经手的收款算应有现金和长短款；后台“交班记录”可查询、导出。不开班也照常收银 |
