# 收银系统：第一期进度与上线差距（2026-11-14）

## 一、第一期完成情况（后台 + 门店工作台 + API）

| 需求 | 状态 | 说明 |
| --- | --- | --- |
| 1 后台 / 门店分开、权限 | 完成 | 后台角色、门店角色；权限点 14 个；员工可绑定多家门店；营收只开放后台 |
| 2 商品、分类、供应商、图片、医疗器械资料 | 完成 | 两级分类；供应商在表单最下面；注册证号、生产许可证号、注册人、生产地址 |
| 3 多规格、不同名称共用库存品、扣减量 | 完成 | 规格绑定库存品 + 扣减量（可小数）；取消、退货按状态回补 |
| 4 收银、扫码、打折、调低应收 | 完成 | 只能调低；不改原价；库存照件数扣；能否打折 / 调低、最低折扣、单笔最多调低可按角色和账号设置 |
| 5 独立订单、接单、收款、取消、退货退款、防重复 | 完成 | 部分退；默认回原门店库存，可选不回；带请求号的操作只生效一次 |
| 6 区域二维码识别门店和区域 | 完成（网页版） | 小程序尚未开发（第二期） |
| 7 新订单提示音、自动打印、补打 | 完成（浏览器打印） | 静默出票需 Chrome `--kiosk-printing`；小票机型号确认后再做直连 |
| 8 小票内容可配置、底部图片 | 完成 | 实时预览、测试页 |
| 9 仓库 / 门店库存、调拨、期初入出结余 | 完成 | 台账可点数字看流水；门店盘点需后台允许 |
| 10 营收报表、导出、商品销售逐单明细 | 完成 | 日 / 周 / 月，按门店；退款、优惠计入；Excel 导出 |
| 11 安卓 / 鸿蒙 / iOS 客户端 | 未开始 | 第三期 |

测试：后端 23 个接口测试全部通过；后台各页面、门店收银（打折 + 抹角 + 现金找零）、扫码点单 → 门店接单 → 收款 → 部分退货，已在本机浏览器走通，营收和台账数字核对一致。

**收款说明**：收银和订单收款中的现金、微信、支付宝、其他，都是“店员确认已收款”后记账，不是在线支付。

## 二、后续阶段

**第二期：微信小程序**（需要小程序账号）
1. 注册微信小程序（企业主体，用营业执照）并认证。
2. 用 uni-app 写小程序端，接口已经现成（`/api/customer/*`），登录改为 `wx.login`。
3. 区域二维码改为小程序码。
4. 云服务器 + 备案域名 + HTTPS，真机测试，提交审核。

**第三期：客户端与打印**
1. uni-app 打包安卓 APK、鸿蒙、iOS 客户端（门店工作台 / 后台的移动版）。
2. 确定小票机型号后，做 ESC/POS 直连打印（后端已生成纯文本小票）。
3. 如需在线支付：申请微信支付 / 支付宝商户号，接入自动扣款和原路退款。

## 三、距正式上线还差什么

| 工作 | 说明 |
